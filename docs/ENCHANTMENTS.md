# Enchantment Plan

The first release focuses on utility. Initial concepts below are proposals, not promises that every mechanic is supported by the current Bedrock Script API.

## Utility — first priority

| Enchantment | Equipment | Intended effect | Status |
|---|---|---|---|
| Vitality I–III | Chestplate | Gradual passive health regeneration | Planned |
| Anchor I–III | Boots | Reduce knockback | Planned |
| Aquatic I–III | Helmet | Improve underwater movement/utility | Planned |
| Prospector I–III | Pickaxe | Chance for bonus mining drops | Planned |
| Lumberjack I–III | Axe | Help collect connected logs | Planned |
| Angler's Luck I–III | Fishing rod | Improve fishing utility | Planned |
| Wayfinder | Compass | Navigation assistance | Planned |

## Later categories

- Combat enchantments: design after the utility foundation is stable.
- Rare/legendary enchantments: later progression, with stronger effects and careful balancing.

## Design rules

- Enchant vanilla equipment only in the initial scope.
- Prefer clear, predictable effects over random complexity.
- Avoid excessive particle spam, tick-heavy scans, and unnecessary entity iteration.
- Make levels meaningful and balanced.
- Confirm API support before finalizing an effect.
